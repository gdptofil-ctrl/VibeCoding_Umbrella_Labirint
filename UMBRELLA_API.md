# Umbrella Lua API v2.0 — compact reference

Generated from the official docs (https://uczone.gitbook.io/api-v2.0) on 2026-09-27.
One line per function. `[x]` = optional parameter. Grep this file instead of
guessing: if a function is not here, it does not exist.

Sections: `## Callbacks`, `## <Namespace>` for static tables (`NPC.Foo(npc)`),
`## class <Name>` for methods (`vec:Foo()`), `## Enum.<Group>` for constants.

## Callbacks

Return a table from your script; these keys are called by the cheat.

- `OnChatEvent(data)` — Called on chat event.
- `OnDraw()` — Called when the game is drawing. Works only in the game.
- `OnEntityCreate(entity)` — Called when a new entity is created.
- `OnEntityDestroy(entity)` — Called when an entity is destroyed.
- `OnEntityHurt(data)` — Called when an entity is hurt.
- `OnEntityKilled(data)` — Called when an entity is killed.
- `OnFireEventClient(data)` — Called when a game event is fired.
- `OnFrame()` — The same as OnDraw, but called in the menu too.
- `OnGCMessage(data)` — Called when a game coordinator protobuff message is received. Return false to prevent the message
- `OnGameEnd()` — Called on game end.
- `OnGameRulesStateChange(data)` — Called on gamestate change.
- `OnKeyEvent(data)` — Called on key and mouse input. Return false to prevent the event from being processed.
- `OnLinearProjectileCreate(data)` — Called when new linear projectile is created.
- `OnLinearProjectileDestroy(data)` — Called when linear projectile is destroyed.
- `OnModifierCreate(entity, modifier)` — Called when a modifier is created.
- `OnModifierDestroy(entity, modifier)` — Called when a modifier is destroyed.
- `OnModifierUpdate(entity, modifier)` — Called when a modifier is updated/refreshed.
- `OnNpcDying(npc)` — Called on NPC dying.
- `OnNpcSpawned(npc)` — Called when a npc is spawned. Unlike OnAddEntity, the entity is fully initialized here.
- `OnOverHeadEvent(data)` — Called on event above the hero's head.
- `OnParticleCreate(data)` — Called when new particle is created.
- `OnParticleDestroy(data)` — Called when particle is destroyed.
- `OnParticleUpdate(data)` — Called when particle is updated.
- `OnParticleUpdateEntity(data)` — Called when particle is updated on entity.
- `OnParticleUpdateFallback(data)` — Called when particle is updated. Alternative version for some particles.
- `OnPostReceivedNetMessage(data)` — Called when a net message is received. Return false to prevent the message from being recieved
- `OnPreHumanizer()` — TODO
- `OnPrepareUnitOrders(data)` — Called on every player order. Return false to prevent the order from being executed.
- `OnProjectile(data)` — Called when new projectile is created.
- `OnProjectileLoc(data)` — Called when new projectile loc is created.
- `OnScriptsLoaded()` — Called after all scripts are loaded.
- `OnSendNetMessage(data)` — Called when a net message is sent. Return false to prevent the message from being sent. See
- `OnSetDormant(npc, type)` — Called on NPC dormancy state changed.
- `OnSpeak(data)` — Called every time unit/announcer talk. You could return false to prevent the sound from being played.
- `OnStartSound(data)` — Called when sound is started.
- `OnThemeUpdate()` — Called when the UI theme colors are changed.
- `OnUnitAddGesture(data)` — Called when a unit is added to a gesture.
- `OnUnitAnimation(data)` — Called when a unit animation is played.
- `OnUnitAnimationEnd(data)` — Called when a unit animation ends.
- `OnUnitInventoryUpdated(data)` — Called on unit inventory updated.
- `OnUpdate()` — Called every game update. Works only in the game.
- `OnUpdateEx()` — Called every game update. Same as OnUpdate but as well called in the menu.

## Abilities

- `Abilities.Contains(ability)` -> boolean — Check ability in cheat list.
- `Abilities.Count()` -> integer — Return size of ability list.
- `Abilities.Get(index)` -> CAbility | nil — Return ability by index in cheat list. Not the same as in-game index.
- `Abilities.GetAll()` -> CAbility[] — Return all abilities in cheat list.

## Ability

- `Ability.CanBeExecuted(ability)` -> Enum.AbilityCastResult — Returns -1 if ability can be executed.
- `Ability.CanBeUpgraded(ability)` -> boolean — Returns if the ability is upgradable with a specific reason.
- `Ability.CastNoTarget(ability, [queue], [push], [execute_fast], [identifier])` -> nil — Casts the ability that doesn't require a target or position.
- `Ability.CastPosition(ability, pos, [queue], [push], [execute_fast], [identifier], [force_minimap])` -> nil — Casts the ability at a specified position.
- `Ability.CastTarget(ability, target, [queue], [push], [execute_fast], [identifier])` -> nil — Casts the ability on a specified target.
- `Ability.ChargeRestoreTimeRemaining(ability)` -> integer — Returns the remaining time for the next charge to restore.
- `Ability.GetAbilityID(ability)` -> integer — Returns ability id
- `Ability.GetAltCastState(ability)` -> boolean — Returns the alt cast state of the ability. Example: Doom's Devour.
- `Ability.GetAutoCastState(ability)` -> boolean — Returns the autocast state of the ability.
- `Ability.GetBaseName(ability)` -> string — Returns the ability base name or empty string.
- `Ability.GetBehavior(ability, [from_static_data])` -> Enum.AbilityBehavior — Returns the ability type.
- `Ability.GetCastPoint(ability, [include_modifiers])` -> number — Gets the cast delay of this Ability.
