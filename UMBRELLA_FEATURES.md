# Встроенный функционал Umbrella

Выжимка с https://umbrella-dota.com/funkcii/ (снято 2026-10-25, страницы помечены «обновление 15.09.2026»).
Это то, что чит умеет **сам**, без Lua. Перед тем как писать новый скрипт — проверь, что его нет здесь.
Скрипты на героев («400+ на 126 героев») списком не опубликованы — открыты только страницы Pudge, Lion, Invoker.

HP Рошана (экран/яма), таймеры рун, напоминание о стаке. Варды врага (2D/3D, радиус), «тебя видят». HP/MP/ульт-бары, Top Display, модификаторы с длительностью, инвентари, нетворс. ## Чего здесь нет (свободные ниши)

По этому списку **не покрыто** встроенным: анализ своей игры и обучение, долгосрочная статистика по
своим матчам (кроме MMR), логика под конкретные механики героя сверх комбо/добивания (PRD, Infest,
выбор позиции ульты), координация с тиммейтами, всё вне матча.
