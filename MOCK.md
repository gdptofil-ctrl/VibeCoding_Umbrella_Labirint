# mock — прогон скриптов Umbrella без доты

Запускает твой скрипт в обычном Lua 5.4 на фальшивом мире: герой, свои юниты, враги, время,
меню. Отдаёт отчёт, что пошло не так. Нужен чтобы нейронка (или ты) ловила ошибки до того,
как скрипт попадёт в игру.

```bash
lua mock/run.lua мой_скрипт.lua
```

Код выхода `0` — чисто, `1` — есть проблемы. Агент может крутить «поправил → прогнал»
сам, пока не станет 0.

## Что ловит

- **Функции, которых нет в API.** Сверка идёт с официальной документацией v2.0. Для каждой —
  строка в твоём файле и что ты скорее всего имел в виду:
  `NPC.GetPosition  мой.lua:29  -> Entity.GetAbsOrigin`.
- **Правильная функция не на той таблице:** `NPC.GetHealth -> Entity.GetHealth`.
- **Не то число аргументов:** `World.GetGroundZ(vec)` вместо `World.GetGroundZ(x, y)`.
- **Опечатки в енамах:** `DOTA_UNIT_ORDER_MOVE -> DOTA_UNIT_ORDER_MOVE_TO_POSITION / ...`.
- **Колбэк, который никогда не вызовется:** `script.OnUpdte -> OnUpdate`.
- **Меню, которое не построится:** `Switch` у таба вместо группы.
- **Ошибки Lua** с обрезанным до твоих строк трейсбэком и подсказкой. Например, если функция
  вернула nil, а ты это не проверил, или `math.atan2`, которого в Lua 5.4 нет.
- **Спам приказами:** сколько приказов в секунду получает каждый юнит, сколько из них дубли.
- **Отменённые удары:** если приказ приходит посреди замаха, урона нет — мок считает, сколько
  ударов начато, дошло и отменено.

## Как нажимать кнопки

Бинды из твоего меню нажимаются по имени, номеру или куску имени:

```bash
lua mock/run.lua micro_demo.lua --press 30:"За мной"     # на 30-м тике
lua mock/run.lua micro_demo.lua --press 30:#1            # первый бинд в меню
lua mock/run.lua micro_demo.lua --press 30:Охран         # по куску имени
lua mock/run.lua micro_demo.lua --hold 30-90:"Кайт"      # держать с 30 по 90 тик
lua mock/run.lua micro_demo.lua --set "Включить=false"   # выставить галочку/слайдер
```

Если имя не нашлось, отчёт напишет, какие бинды есть, с номерами.

## Флаги

| Флаг | Что делает |
| --- | --- |
| `--ticks N` | сколько тиков гонять (по умолчанию 300 = 10 секунд) |
| `--tps N` | тиков в секунду (30) |
| `--press T:Имя` | нажать бинд на тике T |
| `--hold A-B:Имя` | держать бинд с тика A по B |
| `--set Имя=значение` | выставить виджет меню перед стартом |
| `--cursor X,Y` | куда смотрит курсор в мире |
| `--scenario файл.lua` | свой мир (см. ниже) |
| `--keep-going` | не падать на несуществующих функциях, а вернуть nil и ехать дальше — один прогон покажет **все** ошибки, а не первую в каждом колбэке |
| `--brief` | только проблемы и итоги |
| `--echo` | печатать `print`/`log` скрипта сразу |

## Свой мир

`mock/examples/scenario.lua` — пример со всеми полями: какой герой, какие юниты твои, какие
враги, маршрут героя, стены, нажатия, настройки. Любое поле можно не указывать.

## Бой и клики

- у врага `attack = "hero"` - он лезет бить героя и продолжает после каждого воскрешения
- `respawn = 6` - герой воскресает через 6 сек на месте старта
- `clicks` - приказы как будто от игрока, проходят через твой `OnPrepareUnitOrders`:
  `{ tick = 60, order = "DOTA_UNIT_ORDER_CAST_NO_TARGET", ability = "lycan_howl" }`,
  для атаки `target = "enemy"` (ближайший вражеский герой)
- удары присылают `OnEntityHurt` и `OnEntityKilled`, а `Player.GetTeamData` / `GetTeamPlayer`
  отдают киллы, смерти, ластхиты и урон по героям из этого боя
- после конца игры мок рисует еще 5 кадров, так что карточки итогов и прочее на `OnGameEnd` тоже проверяются

## Чего мок не умеет

Это не эмулятор доты. Функции, которые он не симулирует, возвращают значение-заглушку нужного
типа (`false`, `0`, `""`, `{}`, `nil`) и перечисляются в отчёте в разделе «не симулируется».
Логику, которая от них зависит, прогон по-настоящему не проверил.

Чит знает вещи, которых нет в документации, например глобалы `XHelpers` и `db`. Мок о них
не знает и честно скажет, что таких нет. Если скрипт на них завязан — подсунь заглушку в
сценарии через `globals`.

Вопрос «работает ли это в игре» мок не закрывает. Он закрывает вопрос «есть ли тут очевидная
ошибка, которую видно без игры», и таких ошибок в AI-скриптах большинство.

## Если вышла новая версия API

```bash
python mock/tools/update_api.py
```

Скачивает документацию заново и перегенерирует `mock/surface.lua` и `UMBRELLA_API.md`.

## Установка Lua

Нужен Lua 5.4. На Windows:

```bash
winget install DEVCOM.Lua
```

Если кириллица в `--press` не находится — используй номер (`#1`) или кусок имени.
Для читаемого вывода в `cmd` включи UTF-8: `chcp 65001`.
