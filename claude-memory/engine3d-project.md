Built 2026-10-01 in `Downloads\scripts`: `engine3d.lua` + `engine3d/` (portal sector renderer drawn with
`Render.Image` UV column strips), DOOM example with procedural levels, sandbox template, browser level
editor `engine3d/tools/editor.html`, docs `ENGINE3D.md`. A zip copy was also put on the Desktop
(`C:\Users\gdpto\Desktop\engine3d.zip`).

The user's goals: an engine **other users** build their own games on (DOOM is only the example);
entry from the Umbrella menu; mouse look by cursor preferred over arrows; 64x64 textures but any size
must work; Dota input is simply blocked while playing. They first asked for custom 3D models inside
Dota, dropped it once I explained the API cannot load models (only overlay drawing).

**Why:** next sessions will likely be bug reports from running it in the real game.

The active cheat dir is `C:\Users\gdpto\Downloads\` (debug.log, images\ live there; the AppData copy
is stale). Verified in game 2026-10-01: input works, 117 fps at 320 cols, but `Render.LoadImage` loads
nothing from `scripts\` (any path form). Fix shipped: PNGs mirrored into `<cheat>\images\engine3d\...`
loaded as `"~/engine3d/..."` (`~/` = images folder, inferred from other scripts like `"~/bearmon/"`),
plus an SVG-embedded-PNG fallback via `Render.LoadSvgString`. Also learned: OnDraw runs only in a match,
OnKeyEvent everywhere (first build locked the user's input outside a match).

Second in-game test (same day): `"~/..."` from images\ ALSO failed; only the SVG path works
(`Render.LoadSvgString` with a base64 PNG inside `<image>`), so the engine now ships textures as
`pack.lua` (tools/pack_textures.py or the editor's "Упаковать .lua"); images\ copy removed. UV > 1 does
NOT wrap (clamps, vertical streaks), so walls are always split into tiles. User liked the result
("заебись") and asked for more games: built "Последний автобус" (games/bus) from their story spec;
they said "пару игр" but only described one — a second may follow.

Third in-game test: bus game crashed at start — the cheat sandbox has NO `coroutine` global. Story
system rewritten as step lists (engine3d/story.lua); mock/run.lua and my offline harness now set
`coroutine = nil` (harness also `utf8 = nil`). Lesson: my offline tests ran plain Lua and missed
sandbox-only gaps; recorded in CLAUDE.md "Грабли".

Sound (same day): `Engine.PlayVol` takes a Dota sound FILE path ("sounds/ui/ping_warning.vsnd_c",
how the user's other scripts use it), not an event name. Dota install: C:\Program Files (x86)\Steam\...
\dota 2 beta\game\dota\pak01_dir.vpk; engine3d/tools/find_sounds.py lists paths + durations.
engine3d/sound.lua plays one-shots/loops/ambience; no way to stop a playing sound. PushClip was
dropped from sprites (in-game it seemed not to clip).
